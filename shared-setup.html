1. Anonymous sign-in

In Firebase Authentication → Sign-in method, keep Anonymous enabled. If it was enabled for Activities, leave it enabled; no new password or account is needed.

2. Publish the combined database rules

Click Copy rules. Open Firebase Realtime Database → Rules, replace the code and click Publish. These add X-section access while preserving the other application rules. This does not replace database data.
